## How This System Works

1. **Strategy Layer** — Phase-wise plan calibrated to 3-4 hrs/day
2. **Knowledge Layer** — Subject-wise prep with UPSC-lens filtering
3. **Practice Layer** — Daily MCQ drills with elimination technique training
4. **Current Affairs Engine** — Weekly digests filtered for UPSC relevance
5. **Analytics Layer** — PYQ pattern analysis driving topic prioritization
6. **Mindset Layer** — Anti-overthinking protocols and exam simulation
