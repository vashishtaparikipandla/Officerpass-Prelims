# PYQ Analysis Framework

> This folder will contain analysis of previous year question papers.
> Upload your PYQ booklets here, and I'll analyze them for patterns.

---

## What I'll Analyze

### 1. Subject-Wise Distribution
- How many questions from each subject per year
- Trends: Is Polity increasing? Is History decreasing?
- Subject-wise cutoff contribution

### 2. Topic-Wise Hotspots
- Specific topics asked repeatedly (e.g., "Fundamental Rights" in Polity)
- Topics that appear every year vs. rotating topics
- New topics that appeared for the first time recently

### 3. Difficulty Trends
- Are questions getting more factual or conceptual?
- Ratio of direct questions vs. application-based
- Current affairs integration level per year

### 4. Question Type Patterns
- "Which of the following is/are correct?" — frequency and trap patterns
- Match the following — common combinations
- Assertion-Reason — frequency trends
- Map-based questions

### 5. Answer Distribution
- Is there a bias toward certain options (a/b/c/d)?
- "All of the above" / "None of the above" frequency
- "1 and 3 only" type combination patterns

### 6. Your Personal Pattern (after you share your responses)
- Where you scored vs. where you lost marks
- Subject-wise accuracy
- Overthinking-induced errors
- Time management issues
